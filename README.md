# 前端面试刷题（选择题版）

个人前端面试刷题工具，支持单文件离线使用，以及单账号登录后自动同步到自己的服务器。

- **题库**：196 道单选题，覆盖 JavaScript / Vue / React / 网络 / CSS / HTML / 浏览器 / 性能优化 / 工程化 / Node.js / 场景设计 / TypeScript / 设计模式 共 13 个分类。
- **内容来源**：由《前端热门面试题 200 道速记通关版》整理改写为单选题（含逐题专属解析与逐项判定理由）。原始 PDF 未包含在本仓库中。
- **功能**
  - 每轮从勾选的类型中随机抽题，总题数可选 10/20/30 或自定义（1–196 题），取消勾选即可排除类型
  - 每轮题目不重复；所选类型题量不足时抽取全部可用题目，全未选时提示先选择类型
  - 新练习随机排列选项；同一轮刷新、继续或云端恢复后保持顺序，快捷键和解析按显示顺序对应
  - 抽题权重：未刷题与错题本中的题目为 4，已刷非错题为 1；降低重复概率但不完全排除
  - 兼容旧浏览器记录、旧 JSON 导出与旧服务器记录；旧练习继续使用原选项顺序，原始浏览器记录转换前保留备份
  - 选完立即判分：正确项标绿、误选项标红，每个选项附带一句「为什么对/错在哪」
  - 答错自动进入错题本，同一题连对 2 次自动移出
  - 随机抽一题、收藏、全题库搜索与分类筛选
  - 正确率统计、最近记录、断点续刷
  - 云端版：单账号登录，错题、收藏、统计、出题设置、未完成练习保存到服务器
  - 断网暂存本机、自动重试、多设备版本冲突提示、JSON 记录导出与导入
  - 快捷键：`A/B/C/D` 或 `1-4` 选答案，`Enter` 下一题，`R` 换题，`Esc` 关闭弹窗
- **数据存储**：离线版保存在浏览器 localStorage；云端版保存到自建服务器的 SQLite 数据库，浏览器缓存待上传记录。

## 1Panel 部署（推荐用于跨设备刷题）

已提供 [自动部署流水线与首次接入说明](docs/automatic-deploy.md)：推送 main 后自动测试、构建和验证镜像；服务器接入完成并启用部署变量后自动备份、更新、健康检查及失败回滚。

提供 Dockerfile、compose.yaml 和环境变量示例，无第三方运行依赖，无需安装 MySQL 或 Redis。

1. 将完整项目上传服务器，复制 `.env.example` 为 `.env`。
2. 填写个人用户名、至少 12 位密码、实际站点 `PUBLIC_URL`。
3. 在项目目录执行 `docker compose up -d --build`，或通过 1Panel 的容器编排启动。
4. 配置反向代理和 HTTPS，登录后即可使用。

完整说明见 [1Panel 部署、旧记录迁移、备份与密码重置](docs/1panel-deploy.md)。账号只在首次启动时创建，不开放注册。密码加盐哈希保存；会话使用 HttpOnly Cookie；数据库放在持久化数据卷。

## 本地启动后端

需要 Node.js 22.13+，部署镜像使用 Node.js 24 LTS。使用内置 SQLite，本地较早版本可能提示实验性 API 警告。

```sh
cp .env.example .env
# 编辑 .env：配置账号密码，PUBLIC_URL=http://localhost:3000，COOKIE_SECURE=false
npm start
```

访问 `http://localhost:3000`。后端不需要 `npm install`。默认监听本机，数据库保存在 `data/quiz.sqlite`；密码和数据库不会提交到 Git。

验证：`npm test`。覆盖 HTTP 鉴权、持久化、冲突、输入校验、同步重试和原有抽题功能。

## 本地使用

直接用浏览器打开 `index.html` 即可，无需安装任何依赖。此模式不连接后端，数据仅在当前浏览器中。

## 仅部署离线版

任选其一：

- **GitHub Pages**：仓库已开启，访问 `https://<用户名>.github.io/fe-interview-quiz/`
- **自己的服务器**：把 `index.html` 放到 Nginx 站点根目录即可
- **Vercel / Netlify / 对象存储**：作为静态站点直接上传该文件

## 更新

离线版替换 `index.html` 即可。云端版更新整个项目后运行 `docker compose up -d --build`，保留原数据卷；不要执行 `docker compose down -v`。
