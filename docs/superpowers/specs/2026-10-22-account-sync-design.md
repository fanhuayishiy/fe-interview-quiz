# 单账号云端刷题数据

用户确认仅个人使用，采用 Node.js 原生 HTTP + SQLite，不开放注册。前后端由同一服务提供，容器部署到 1Panel，域名经 OpenResty 代理并启用 HTTPS。

账号在首次启动时从环境变量初始化。密码使用 scrypt 加盐哈希，随机会话通过 HttpOnly、SameSite=Strict Cookie 保存，生产启用 Secure。限制登录尝试，写操作检查来源和 JSON 请求头。数据与账号表不通过静态服务暴露。

保存全部 wrong、fav、seen、rounds、session、settings。每次写入携带版本号，服务端条件更新；冲突不自动覆盖，用户可下载本地副本、使用服务器版本或明确上传本地版本。本地缓存待上传记录，断网提示并重试；登录失效要求重新登录。

初次登录从服务端读取数据。服务端无记录且本地存在数据时提示导入；服务端已有数据时优先使用服务器版本，保留本地备份。旧文件和 GitHub Pages 可导出 JSON，再在新站点导入；导入覆盖必须确认。导入和上传均校验结构与题目 ID。

单文件离线版继续可用，服务器仅在 HTTP 返回页面时注入同步资源。提供 Dockerfile、Compose、环境变量示例、数据目录持久化、停止服务后备份与恢复说明。

验证包括真实 HTTP 登录/登出/会话、未授权、限流、非法来源、数据校验、写冲突、重启持久化，以及前端旧数据导入、保存和多设备恢复。
